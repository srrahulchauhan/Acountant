# Accountant - Personal Finance & Khata Management OS

A luxury, high-performance personal finance and credit ledger web application built for individuals, freelancers, and students. Inspired by modern fintech tools like Revolut and Linear, Accountant helps you manage daily expenses, maintain a credit book (Udhaar Khata) with automated WhatsApp reminders, track EMI loan payments, and monitor multi-account balances.

---

## 🌟 Key Features

- **📊 Financial Command Center (Dashboard)**
  - Dynamic time-based greetings (Good Morning, Afternoon, Evening, Night).
  - Live animated KPI metric cards with privacy balance masking (`Eye`/`EyeOff`).
  - Interactive Daily Expense Analytics AreaChart with amber gradient glow.
  - Category share breakdown with dynamic progress bars.
  - Upcoming EMI schedule with tenure progress and one-click payment celebration.
  - Udhaar collection list with direct 1-click WhatsApp payment reminders.

- **💸 Daily Expenses Ledger**
  - Instant logging with category tags (Food, Travel, Bills, Shopping, Health, Education, Entertainment).
  - Time filters (Today, This Month, All Time) & payment channel filters.
  - CSV export for spreadsheets.

- **📖 Udhaar Khata (Credit Book)**
  - Keep track of money lent to friends and money owed to vendors.
  - Real-time **Net Balance Position** calculator.
  - Direct **WhatsApp Reminder Trigger** (`https://wa.me/?text=...`) with pre-composed polite reminders.
  - Settlement with celebratory confetti.

- **💳 EMI & Loan Portfolio Tracker**
  - Track vehicle, smartphone, appliance, and personal loan tenors.
  - Overall debt paydown progress bar.
  - Real-time tenure countdown and balance calculation.

- **🏦 Treasury & Account Statements**
  - Realistic physical card style accounts (HDFC Bank, Paytm UPI Wallet, Cash Reserve).
  - Fast internal funds transfers between accounts.
  - Searchable audit trail and CSV download.

- **📈 Reports & Financial Intelligence**
  - Financial Health Score meter (out of 100) with personalized budgeting advice.
  - Category distribution donut chart & daily spend volume bar chart.
  - Top highest expenses table.

- **⚙️ Settings & Privacy**
  - Dark mode (Deep space obsidian `#070B14`) and Light mode.
  - Complete JSON backup export and restore.
  - Reset to demo data option.

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS + Custom Ambient Mesh Design System
- **Icons**: Lucide React
- **Visualizations**: Recharts
- **Animations**: Framer Motion + Canvas Confetti
- **Typography**: Outfit, Plus Jakarta Sans, JetBrains Mono

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/srrahulchauhan/Acountant.git
cd Acountant
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for production
```bash
npm run build
```
